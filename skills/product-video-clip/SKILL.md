# 상품 영상 한 컷 만들기 (4~15초)

## 1. 무엇을 하나

사람이 상품을 들거나, 쓰거나, 보여 주는 짧은 영상 한 컷을 AI 로 만듭니다.
상세페이지, 스마트스토어 대표 영상, 쇼핑라이브 중간 화면, 릴스와 쇼츠에 씁니다.

| 단계 | Claude 가 하는 일 | 돈 |
|---|---|---|
| 지시문 짜기 | 상품 사실로 영어 지시문을 씁니다 | 0 |
| 점검 | 점검표로 지시문을 검사합니다 | 0 |
| 첫 장 그림 | 좋은 시작 사진이 없으면 그림부터 만듭니다 | 조금 |
| 영상 만들기 | 비용을 먼저 보여 드리고 «좋아요»를 기다립니다 | 큼 |
| 판정 | 1초 간격 화면으로 결과를 봅니다 | 0 |
| 고치기 | 고칠 곳을 지시문 문장으로 바꿔 드립니다 | 다시 만들 때만 |

## 2. 준비물

| 준비물 | 왜 |
|---|---|
| 상품 실물 사진 1장(글자, 스티커, 배경 소품 없는 깨끗한 컷) | AI 가 모양과 색을 따라 그리는 기준입니다 |
| 상품 사실 몇 줄(크기, 색, 버튼 위치, 실제로 되는 기능) | 없는 기능을 영상에 넣지 않으려고 |
| 어디에 쓸지(세로 9:16, 가로 16:9, 정사각) | 화면 비율을 정합니다 |
| 영상 도구(claude.ai 에 Higgsfield 연결, 또는 쓰시는 영상 AI) | 실제로 만드는 곳입니다 |
| 남은 크레딧이나 예산 | 한 번에 얼마까지 쓸지 정합니다 |

사람 얼굴 사진은 참조로 넣지 않는 편이 낫습니다. 실제 사람 얼굴은 막는 영상 도구가 많습니다. 사람은 글로 그립니다(머리 모양, 옷 색).

## 3. 첫 한마디 예시

- «이 텀블러 사진으로, 손이 텀블러를 들어 올리는 8초 세로 영상 만들어 줘.»
- «이 지시문 봐 줘. 돈 쓰기 전에 고칠 데 있어?» (지시문 붙여 넣기)
- «영상 나왔는데 손가락이 엉켰어. 캡처 올릴게, 어떻게 고쳐?»

## 4. 절차

1. **상품 사실 받기.** 셀러 원문, 상세페이지에 있는 것만 씁니다. 모르면 묻습니다.
2. **한 컷에 할 일 하나 정하기.** «들어 올린다», «뚜껑을 연다», «버튼을 누른다» 중 하나.
3. **시작 사진 정하기.** 되도록 «사진 → 영상»(image to video)으로 갑니다.
   - 상품이 또렷한 시작 사진이 있으면 그것을 첫 장으로 씁니다.
   - 없으면 그림 도구(Nano Banana Pro, Seedream)로 «상품이 놓인 장면» 한 장을 먼저 만듭니다. 그림이 영상보다 훨씬 쌉니다.
   - 첫 장 그림에서 상품 모양, 색, 글자를 먼저 판정합니다. 첫 장이 틀리면 영상도 틀립니다.
4. **지시문 쓰기.** 5번 «지시문 짜는 법» 꼴로 씁니다.
5. **점검표 돌리기.** 6번 표에서 ⛔ 가 하나라도 있으면 만들지 않고 고칩니다.
6. **비용 보여 드리기.** 모델, 길이, 해상도, 후보 수, 예상 크레딧을 표로 보여 드리고 «좋아요»를 기다립니다. 대답 없이는 만들지 않습니다.
7. **만들기.** 후보는 2개를 권합니다. 둘 중 하나는 대개 쓸 만합니다.
8. **판정.** 7번 점검표로 봅니다. 1초마다 캡처한 화면을 올려 주시면 Claude 가 칸마다 봅니다.
9. **고치기 또는 합격.** 고칠 곳은 «바꿀 문장»으로 드립니다. 같은 실수로 두 번 넘게 다시 만들지 않고, 컷을 나누거나 동작을 바꿉니다.
10. **올리기 전 점검.** 8번 «지키는 것»과 납품 점검을 봅니다.

**모델 고르기(대략)**

| 장면 | 권하는 쪽 |
|---|---|
| 사람 손, 몸이 나오고 동작이 중요함 | 씨댄스 2.5 같은 상위 모델 |
| 상품만 돌거나 놓여 있음 | 빠르고 싼 모델 |
| 구도만 연습 | 가장 낮은 해상도 |

정확한 크레딧은 도구가 알려 주는 값을 그대로 보여 드립니다. Claude 가 짐작한 숫자는 쓰지 않습니다.

## 5. 지시문 짜는 법

### 다섯 규칙

| 규칙 | 이렇게 | 어기면 |
|---|---|---|
| 1. 한 컷에 변화 하나 | 동작 하나만. «벗고 → 걸고 → 앉는다»를 4초에 넣지 않습니다 | 팔이 엉키고 뒤 동작이 뭉개집니다 |
| 2. 과정 대신 결과 | 다음 컷에 «이미 걸려 있는 외투»처럼 결과를 보여 줍니다 | 하는 도중 장면이 망가집니다 |
| 3. «안 한다» 대신 «일어나는 일» | «바람 없음» 대신 «종이가 책상에 평평하게 놓여 있다». «제품이 빛나지 않음» 대신 «탁상 스탠드가 바닥을 비춘다» | 부정한 낱말 쪽으로 끌려 그 일이 생깁니다(없는 빛, 없는 연기) |
| 4. 같은 사람, 같은 카메라 | 컷마다 머리와 옷 색을 다시 적고 «the same person». 카메라 자리를 못 박습니다 | 컷마다 사람이 바뀝니다 |
| 5. 참조 사진 역할 한 줄 | «The reference image controls only the product's shape, colour and details, not the composition or background.» 배경 낱말은 한 곳만 | 사진 속 배경까지 따라 그리거나 배경 둘이 섞입니다 |

### 꼴

- 시간 표기: `Shot 1 [0:00-0:04]:` `Shot 2 [0:04-0:08]:`
- 상품 생김새를 한 문장으로 못 박고, 컷마다 색 낱말을 똑같이 되풀이합니다.
- 끝 줄은 늘 «No subtitles, no captions, no on-screen text.» (이 줄과 참조 줄의 «not»은 괜찮습니다)
- 지시문은 영어로 씁니다. 대부분의 영상 모델이 영어를 가장 잘 따릅니다.

### 예시 한 벌 (보온 텀블러, 8초, 세로)

```
The reference image controls only the tumbler's shape, colour and details, not the composition or background.
The tumbler is a tall matte sage-green stainless steel tumbler with a flat silver screw lid and a thin silver ring near the top.
Bright Korean kitchen, white counter, soft morning daylight from a window on the left.
Shot 1 [0:00-0:03]: Fixed camera at chest height, medium close-up. The sage-green tumbler stands on the white counter in the centre of the frame.
Shot 2 [0:03-0:08]: A hand with short clean nails, wearing a cream knit sleeve, slowly lifts the same sage-green tumbler to chest height and holds it steady, front side facing the camera, until the end.
Only one hand and forearm are visible. Vertical 9:16 framing.
No subtitles, no captions, no on-screen text.
```

왜 이렇게 썼나: 동작은 «들어 올려 멈춤» 하나, 색 낱말 «sage-green»을 컷마다 되풀이, 카메라 고정, 얼굴 없이 손만, 끝까지 들고 있어 마지막 장면이 깔끔합니다.

## 6. 만들기 전 점검표 (돈 쓰기 전)

| 칸 | 볼 것 | 걸리면 |
|---|---|---|
| ⛔ 길이 | 4~15초 안인가 | 길이를 고칩니다 |
| ⛔ 시작 사진 | 상품 사진이 실제로 붙었나, 실물과 같은가 | 사진부터 고칩니다 |
| ⛔ 없는 기능 | 상세페이지에 없는 기능을 보여 주나(«기울이면 꺼짐» 같은 것) | 그 동작을 뺍니다. 틀린 정보는 반품, 문의로 돌아옵니다 |
| ⛔ 가짜 글자, 로고, 인증 | 인증서, 수상, 다른 브랜드 로고를 그리게 하나 | 뺍니다 |
| ⛔ 실존 인물 | 연예인, 아는 사람 얼굴을 넣나 | 뺍니다. 동의 없는 실제 인물은 쓰지 않습니다 |
| ⚠ 참조 줄 | «The reference image controls only …» 줄이 있나 | 넣습니다 |
| ⚠ 시간 표기 | 컷이 둘 이상이면 `Shot 1 [0:00-0:04]:` 꼴인가 | 고칩니다 |
| ⚠ 글자 0 줄 | 끝에 «No subtitles …» 줄이 있나 | 넣습니다 |
| ⚠ 부정 낱말 | 본문에 not, no, never, without 이 있나 | 일어나는 일로 바꿉니다 |
| ⚠ 한 컷 동작 수 | 한 컷에 then 이 둘 이상인가 | 컷을 나누거나 결과 컷으로 |
| ⚠ 배경 | 배경 낱말이 두 곳 이상인가(«집»과 «사무실») | 하나만 남깁니다 |
| ⚠ 소리 | 소리를 켰다면 음악 낱말(«instrumental», «bell tone»)을 썼나 | 저작권 의심으로 막히기 쉽습니다. 자연 소리로(«room ambience», «fingertip tap on wood») |
| ⚠ 화면 아래 | 쇼핑라이브, 쇼츠처럼 아래에 글자나 상품 카드가 덮이는 곳인가 | 상품을 화면 위쪽, 가운데에 두고 «fixed camera, same size and place», 제자리 동작으로 |

⛔ 가 있으면 만들지 않습니다. ⚠ 는 보여 드리고 고칠지 여쭙니다.

## 7. 결과 판정과 고치는 말

1초마다 한 장씩 캡처해서 보거나, 도구 미리보기를 멈춰 가며 봅니다. 후보 둘은 같은 초끼리 나란히 놓고 비교합니다.

| 볼 곳 | 이러면 탈락 | 고치는 말(지시문에 넣을 문장) |
|---|---|---|
| 상품 모양 | 다른 꼴로 바뀜(낮은 것이 길쭉해짐 등) | 첫 장을 깨끗한 실물 컷으로 바꾸고 생김새를 실루엣으로: «a low, wide, flat shape with rounded corners» |
| 상품 색 | 컷마다 색이 흐름 | 컷마다 «the same matte sage-green colour» 를 되풀이 |
| 손과 팔 | 손가락 6개, 팔이 엉킴, 손이 상품을 뚫음 | 동작 하나로 줄이고 «slowly», 손 수를 못 박기 «one hand only», 길이를 늘려 여유를 줍니다 |
| 사람 | 컷마다 다른 사람 | 컷마다 «the same person with short black hair in a navy jacket», 카메라 자리 고정 |
| 얼굴 | 얼굴이 일그러지거나 실제 누구를 닮음 | 얼굴을 빼기: «seen from behind», «only hands and forearms are visible» |
| 글자 | 상품이나 배경에 읽히는 가짜 글자 | 그 구간을 흐리게 처리하거나 글자 없는 각도로. 진짜 문서는 실물 사진을 씁니다 |
| 빛과 연기 | 실물에 없는 빛, 김, 연기 | 빛의 출처를 다른 물건으로 적기: «a desk lamp lights the floor» |
| 동작 순서 | 뒤 동작이 0.5초로 뭉개짐 | 컷을 나눕니다. 또는 결과 컷으로 |
| 마지막 1초 | 손이 사라지다 말거나 화면이 흔들림 | «holds it steady until the end» |
| 숫자 화면 | 숫자 하나(«0.00»)는 대개 또렷합니다 | 여러 줄 글자는 위 «글자» 처방 |

**판정 말투.** «후보 A 합격. 3초에 손가락이 겹쳐 보이지만 상품 모양과 색은 맞습니다. 쓰셔도 됩니다.»처럼 몇 초, 무엇이, 쓸지 말지를 한 번에 말합니다.

**끝 늘리기(끝 줌).** 영상이 조금 짧으면 마지막 화면을 천천히 1.00 → 1.06배 확대해 2~3초 늘릴 수 있습니다. 편집 앱(캡컷 등)으로 하면 크레딧이 들지 않습니다. 다만 4초 동작 뒤에 10초 넘게 늘리면 멈춘 영상처럼 보입니다. 그럴 땐 동작을 처음부터 길게(예: 12초에 천천히) 다시 만드는 편이 낫습니다.

**다시 만들기 규칙.** 같은 문장으로 두 번 넘게 다시 돌리지 않습니다. 문장을 바꾸거나, 컷을 나누거나, 첫 장 사진을 바꿉니다.

## 8. 지키는 것

**올리기 전 납품 점검**

| 칸 | 볼 것 |
|---|---|
| 파일 | mp4(H.264), 올릴 곳이 받는 크기와 비율인가 |
| 처음과 끝 | 첫 1초가 검은 화면이 아닌가, 끝이 갑자기 끊기지 않나 |
| 멈춤 | 같은 화면이 오래(10초 가까이) 멈춰 있지 않나 |
| 소리 | 소리가 필요 없는 곳이면 소리를 뺐나 |
| 가림 | 올릴 곳의 글자, 버튼, 상품 카드가 상품을 덮지 않나 |

**내용 약속**

- 상품 사실은 셀러 원문, 상세페이지에서만 가져옵니다. 없는 기능, 없는 효과는 보여 주지 않습니다.
- 의학, 건강 효과를 단정하는 장면은 만들지 않습니다(광고법).
- 가짜 글자, 가짜 로고, 가짜 인증서, 가짜 수상 표시는 넣지 않습니다. 진짜 인증은 실물 사진으로 보여 줍니다.
- 남의 브랜드 로고, 캐릭터, 음악은 쓰지 않습니다.
- 실존 인물(연예인, 지인, 손님)은 본인 동의 없이 넣지 않습니다. 도구가 얼굴 사진을 막으면 피해 가려 하지 말고, 글로 그린 가상 인물이나 손만 나오는 장면으로 바꿉니다.
- 아기, 어린이가 나오는 장면은 안전을 해치는 모습(혼자 두기, 위험한 자세)을 만들지 않습니다.
- AI 로 만든 영상은 올리는 곳 규정대로 표시합니다. 예: 네이버 쇼핑라이브는 «AI활용» 표시. 다른 플랫폼도 올리기 전에 규정을 확인합니다.

**돈 약속**

- 크레딧이 드는 일은 늘 비용을 먼저 보여 드리고 «좋아요»를 받은 뒤에 합니다.
- 점검표 ⛔ 가 남은 지시문으로는 만들지 않습니다.
- 얼굴, 저작권 문제로 거절된 요청은 같은 것을 되풀이해 넣지 않고 문장이나 사진을 바꿉니다. 거절에도 크레딧이 나가는지는 도구마다 다르니 내역을 확인합니다.
