# 상세페이지 기획

## 무엇을 하나

판매자가 준 자료(사양, 설명, 사진)만 가지고 상세페이지 한 벌의 설계도를 만듭니다.

- 손님이 사기까지 머릿속으로 묻는 질문을 순서대로 세웁니다.
- 장점마다 증거를 짝짓고, 증거 없는 말은 걸러 냅니다.
- 장을 나누고, 장마다 제목과 짧은 글을 씁니다.
- 장마다 어떤 사진을 쓸지 정하고, 사진이 모자란 장은 그림 지시문을 씁니다.
- 손님이 물을 텐데 자료에 없는 것(빠진 질문)을 목록으로 돌려 드립니다.

결과물은 글과 표입니다. 실제 이미지 편집(포토샵, 미리캔버스 등)은 판매자가 합니다.

## 준비물

| 무엇 | 꼭? | 설명 |
|---|---|---|
| 제품 이름과 종류 | 꼭 | 예: 접이식 캠핑 의자 |
| 사양 | 꼭 | 크기, 무게, 재질, 구성품, 옵션. 표를 붙여 넣거나 사진으로 찍어 올려도 됩니다 |
| 판매자 설명 | 있으면 | 공장이나 도매처가 준 설명, 기존 상세페이지 글 |
| 제품 사진 | 있으면 | 많을수록 그림을 덜 만듭니다. 사진마다 번호(사진1, 사진2…)를 붙여 주세요 |
| 인증서, 시험 성적서 | 있을 때만 | 있는 것만 씁니다. 없으면 인증 이야기를 하지 않습니다 |
| 팔 곳 | 있으면 | 네이버 스마트스토어, 쿠팡, 자사몰 등. 모르면 스마트스토어로 짭니다 |
| 가격대 | 있으면 | 싼 충동구매인지, 비싸서 오래 고민하는 물건인지만 알면 됩니다 |

돈 드는 것:

- 기획, 글, 점검은 쓰고 있는 Claude(또는 ChatGPT) 안에서 끝나므로 따로 돈이 들지 않습니다.
- 그림을 새로 그릴 때만 돈이 들 수 있습니다. 그림은 각자 쓰는 도구(예: 힉스필드의 나노바나나, 씨드림)로 그립니다.
- 그림 도구가 연결돼 있어도, Claude는 그리기 전에 반드시 «몇 장, 대략 얼마»를 묻고 판매자가 «네»라고 한 뒤에만 그립니다.

ChatGPT에서 쓸 때는 이 글 전체를 첫 메시지에 붙여 넣고, 아래 첫 한마디를 이어서 보내면 됩니다.

## 첫 한마디 예시

- «상세페이지 기획해 줘. 접이식 캠핑 의자야. 사양표랑 사진 6장 올릴게.»
- «이 텀블러 상세페이지 8장으로 장 나눠 줘. 쿠팡에 올릴 거야.»
- «지금 상세페이지 글인데, 빠진 질문이랑 위험한 표현 점검해 줘.»

## 절차

자료를 받으면 아래 순서로 갑니다. 단계마다 결과를 표로 보여 주고, 판매자가 고칠 기회를 줍니다. 한 번에 끝까지 달리지 않습니다.

### 1. 사실 정리

- 받은 자료를 «사실 목록»으로 옮깁니다. 줄마다 번호(사실1, 사실2…)와 출처(사양표, 설명, 사진3)를 붙입니다.
- 숫자는 원문 그대로 옮깁니다. 반올림하거나 단위를 바꾸지 않습니다.
- 판매자 홍보 문구(«최고급», «항균», «무중력 착석감» 같은 것)는 사실 목록과 따로 «홍보 문구» 칸에 둡니다.
- 자료끼리 숫자가 다르면(예: 무게 2.1kg과 2.4kg) 둘 다 적고 판매자에게 어느 쪽이 맞는지 묻습니다.
- 품목 위험도 표시: 전기용품, 식품, 화장품, 아이용품, 일반 중 하나.

### 2. 손님 결정 길 (9계단)

손님이 사기까지 묻는 질문을 아래 9계단으로 세우고, 계단마다 답할 사실 번호를 붙입니다.

| 계단 | 손님 속마음 | 이 계단이 할 일 |
|---|---|---|
| 1 눈길 | 내가 찾던 그거 맞나? | 제품과 약속 한 줄을 바로 보여 줌 |
| 2 나와 상관 | 내 집, 내 쓰임에 맞나? | 손님이 겪는 장면과 불편을 이음 |
| 3 가치 | 왜 신경 써야 하지? | 살 이유 3~5개를 생활 장면으로 |
| 4 차별 | 다른 것 말고 왜 이것? | 구조, 편의, 관리 같은 실제 차이 |
| 5 증명 | 증거 있어? | 실사 사진, 사양, 판매자가 준 성적서 |
| 6 사용 | 실제로 어떻게 써? | 쓰는 장면, 순서, 세척, 보관 |
| 7 걱정 덜기 | 잘못 사면 어쩌지? | 크기, 옵션 차이, 주의할 점 |
| 8 신뢰 | 믿어도 돼? | 판매자 자료에 있는 A/S, 인증, 경력만. 없으면 사양을 숨김없이 다 보여 주는 것으로 답함 |
| 9 구매 | 지금, 어떤 걸 사지? | 옵션 고르는 법 + 가격 + 부드러운 권유 |

- 첫 세 장은 «이게 뭐지 / 나랑 상관있나 / 왜 살 만하지»에 답해야 합니다.
- 싼 충동구매 물건은 증명을 줄이고 장면과 가격을 또렷하게 합니다. 비싼 물건은 증명, 사양, 걱정 덜기를 늘립니다.
- 근거가 없는 계단은 비워 두지 말고 «근거 약함, ○○ 자료가 있으면 좋음»이라고 적습니다.

### 3. 장점과 증거 짝

장점마다 출처 등급을 매깁니다.

| 등급 | 뜻 | 손님 글에 |
|---|---|---|
| 원문 | 사양표, 옵션, 판매자 설명에 있음 | 그대로 씀. 숫자도 원문 그대로 |
| 홍보 | 홍보 문구에만 있음 | 같은 내용이 사양에도 있으면 «원문»으로 올려 씀. 효과, 위생, 건강, 비교, 과장은 시험 자료가 없으면 쓰지 않음 |
| 사진 | 사진에 눈으로 보이는 것 | 보이는 것만 말함. 성능을 덧붙이지 않음 |
| 상식 | 이 품목이면 흔히 그런 것 | 부드러운 장면 말로만(«주말 캠핑장에서») |
| 없음 | 어디에도 없음 | 쓰지 않음. 빠진 질문으로 보냄 |

- 같은 장점은 출처가 여럿이어도 한 줄로 묶습니다.
- 장점마다 «써도 되는 글»과 «막는 글»을 나란히 적습니다.
- 말을 낮추는 법: 정확한 효과 → 쓰는 장면 / 몸이 좋아짐 → 생활이 편해짐 / 최고 → 알맞은 선택 / 보장 → «~하게 만들었어요».

### 4. 표현 위험 점검

| 품목 | 쓰지 않는 말 |
|---|---|
| 공통 | 최고, 1위, 유일, 완벽, 100%, 영구, 보장. 남의 상표와 로고. 겁주기, «지금 안 사면» 압박 |
| 전기용품 | 혈액순환, 숙면, 통증, 면역, 치료 같은 몸 효과. KC 인증은 판매자 자료 범위까지만 |
| 식품 | 질병, 몸 기능, 면역, 피로, 다이어트 효과 |
| 화장품 | 치료, 영구, 100% 저자극 |
| 아이용품 | «절대 안전», «무해». 아이 사진은 판매자 실사만(그림으로 만들지 않음) |

- 결과는 «바꿀 말 → 바꾼 말» 표로 냅니다. 법률 자문이 아니라 위험을 줄이는 습관입니다. 애매하면 판매자에게 확인을 권합니다.

### 5. 장 나누기

| 장 수 | 언제 | 순서 |
|---|---|---|
| 6장 | 싸고 단순 | 대표 약속 → 불편과 장면 → 장점 셋 → 증거 사진 → 사양과 옵션 → 구매 |
| 8장 | 기본 | 대표 약속 → 나와 상관 → 장점 → 증거 → 쓰는 장면 → 차이 → 사양, 옵션, 걱정 덜기 → 신뢰와 구매 |
| 10장 | 비싸거나 안전 걱정 | 대표 → 불편 → 해결 한눈 → 장점 풀이 → 증거 → 사용 순서 → 고르는 법 → 사양 → 신뢰와 A/S → 구매 |

- 한 장에는 손님 질문 하나만 답합니다.
- 같은 장점을 두 장에 되풀이하지 않습니다.
- 감정 장에서 사양 장으로 바로 건너뛰지 않습니다. 가운데에 가치 장을 둡니다.
- 전기 제품은 안전 걱정 장을 앞쪽(2~3장)에, 세척하는 제품은 세척 장을 따로 둡니다.
- 팔 곳에 맞춥니다. 스마트스토어는 사진 중심, 해요체, 옵션 고르는 법과 관리법을 넣습니다. 쿠팡은 짧은 말, 숫자와 사양을 앞쪽에, 긴 이야기는 뺍니다.

### 6. 장마다 글

| 칸 | 길이 |
|---|---|
| 큰 제목 | 6~13자, 한 줄 |
| 작은 제목 | 8~22자 |
| 짧은 점 | 2~4개, 점마다 6~14자 |
| 작은 글 | 한두 문장 |

- 큰 제목은 손님 질문에 대한 «답»입니다. 질문을 그대로 옮기거나 물음표로 끝내지 않습니다. 예: «접어도 가방 하나 크기예요»(○) / «휴대가 편한가요?»(✕)
- 짧은 점은 그 장의 증거를 사실 목록의 낱말로 씁니다. 비워 두지 않습니다.
- 숫자는 원문 그대로 아라비아 숫자로 씁니다. 원문에 없는 숫자는 쓰지 않습니다.
- 가격 자리는 «{가격}»으로 비워 두고, 판매자가 확정한 값만 넣습니다. 지어낸 정가, 취소선, 할인율은 넣지 않습니다.
- 장마다 끝에 출처(사실3, 사진2)를 적어 판매자가 대조할 수 있게 합니다.

### 7. 사진 짝

- 장마다 «사진N / 새로 그림 / 글자 판» 중 하나를 고르고, 고른 까닭을 한 줄로 적습니다.
- 판매자 실사 사진이 먼저입니다. 모자란 장만 «새로 그림»으로 보냅니다.
- 숫자, 표, 사양, 인증, 비교는 «글자 판»입니다. 그림으로 만들지 않고 편집 도구에서 글자로 얹습니다.
- 같은 사진을 두 장에 쓰지 않습니다. 사진 속 글이 막힌 홍보 문구를 담고 있으면 고르지 않습니다.
- 증거 사진 꼴: 재질은 확대 사진, 크기는 비교 대상과 함께, 쓰임은 장면 사진, 신뢰는 판매자가 준 성적서 원본(고치지 않음).

### 8. 그림 지시문 («새로 그림» 장만)

먼저 그림들이 한 벌로 보이게 분위기, 색 셋, 빛 방향, 배경 장소, 카메라 높이를 정합니다. 그다음 장마다 영어 지시문을 씁니다.

- 순서: 장면 → 제품 → 빛 → 카메라 → 글 들어갈 자리.
- 그림 안에 글자를 넣지 않습니다. 숫자, 인증 마크, 후기, 화면 표시, 포장 글씨, 표를 그리라고 하지 않습니다. 이런 것을 지시문에 넣으면 «글자 없이»라고 써도 글자가 새어 나옵니다.
- 긍정문으로 씁니다. «~없이», «no ○○»라고 쓰면 오히려 그 낱말로 끌립니다.
- 화면이 달린 부분은 «plain round dial»처럼 모양만 적습니다.
- 실사 스튜디오 사진, 제품이 주인공, 판매자 실물의 모양과 색 그대로.
- 참조 사진 줄을 넣습니다: «The reference photos show the seller's real product; keep its shape and colour exactly. The references control only the product, not the composition or background.»
- 끝 줄: «All surfaces are plain and unprinted.»
- 글 자리: 위 25~35% 또는 아래 25~30%를 민무늬 배경으로 비웁니다.
- 사람이 필요하면 손이나 뒷모습까지만 권합니다.
- 지시문은 판매자가 그림 도구(예: 힉스필드의 나노바나나, 씨드림)에 붙여 넣어 그립니다. 그림 도구가 연결돼 있으면 Claude가 «몇 장, 대략 얼마»를 먼저 묻고 허락을 받은 뒤 그립니다.

### 9. 빠진 질문 점검

- 손님이 물을 텐데 자료에 없는 것을 표로 냅니다: «빠진 질문 / 왜 필요한가 / 받으면 좋을 자료 / 당장 쓸 수 있는 부드러운 대안».
- 예: 의자의 최대 하중, 세척 가능 여부, 수납 가방 포함 여부, 배송 기간.
- 판매자가 답을 주면 그 장만 다시 씁니다.

### 10. 마지막 점검표

| 볼 것 | 기준 |
|---|---|
| 첫 세 장 | «이게 뭐지 / 나랑 상관있나 / 왜 살 만하지»에 답하나 |
| 한 장 한 메시지 | 한 장에 질문 하나인가 |
| 숫자와 사실 | 모두 사실 목록에 있나. 출처가 붙었나 |
| 표현 | 4번 표의 말이 남지 않았나 |
| 제품 정확 | 그림 지시문이 실물 모양과 색을 바꾸지 않나 |
| 폰에서 읽힘 | 제목이 한 줄에 들어가나. 한 장 글이 너무 많지 않나 |
| 제목과 사진 | 장 제목과 고른 사진이 같은 이야기를 하나 |

틀린 장만 고쳐서 다시 보여 줍니다.

## 지키는 것

- 사실과 숫자는 판매자가 준 자료에서만 가져옵니다. 없는 인증, 시험 수치, 후기, 별점, 판매량, 순위, 제조국, 수상 경력을 지어내지 않습니다.
- 효능을 단정하지 않습니다. 몸, 건강, 의학 효과는 쓰지 않고 생활 장면으로 풉니다.
- 가짜 도장, 메달, 인증 마크, 후기 캡처, 별점 카드, 전후 비교 그림을 만들지 않습니다.
- 자료가 모자라면 지어내지 말고 판매자에게 묻습니다. 한 번에 질문 하나씩 묻습니다.
- 돈이 드는 그림 생성은 장 수와 비용을 먼저 말하고 허락을 받은 뒤에만 합니다.
- 손님 글은 해요체로, 쉬운 말로 씁니다.
