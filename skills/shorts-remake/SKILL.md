# 쇼츠 리메이크 (shorts-remake)

잘 된 짧은 영상 하나를 골라 «왜 사람들이 끝까지 봤나»를 초 단위로 뜯어보고, 그 뼈대에 내 상품을 새로 채워 콘티(장면 계획표)를 짜고, AI 로 클립을 만듭니다.

## 무엇을 하나

| 단계 | 하는 일 | 돈 |
|---|---|---|
| 1. 뜯어보기 | 남의 영상을 초 단위 표로 나눕니다 | 0원 |
| 2. 뼈대 뽑기 | 표에서 «구조»만 남깁니다(훅 방식, 박자, 반전 자리, 끝 처리) | 0원 |
| 3. 콘티 | 내 상품, 내 말로 컷 표를 새로 씁니다 | 0원 |
| 4. 시안 그림 | 컷마다 첫 장면 그림을 만들어 구도를 확정합니다 | 조금 |
| 5. 영상 | 확정된 그림에 움직임만 입힙니다 | 큼, 되돌릴 수 없음 |

아래 단계는 거의 공짜이고 위로 갈수록 비싸고 되돌릴 수 없습니다. 그래서 글(1~3)과 그림(4)에서 다 정하고 영상(5)으로 올라갑니다.

## 준비물

- **잘 된 영상 주소 하나**: 같은 갈래 상품에서 조회수, 저장, 댓글이 많은 쇼츠나 릴스.
- **그 영상의 내용**: Claude 는 영상을 직접 볼 수 없습니다. 아래 셋 중 하나를 주세요.
  - 유튜브 자막: 영상 아래 설명란 «더보기» → «스크립트 표시» → 나온 글을 시간과 함께 복사해 붙여 넣기.
  - 장면 캡처: 0초, 1초, 2초, 3초, 그 뒤 장면이 바뀔 때마다 한 장씩(5~10장). 캡처마다 «몇 초»를 적어 주면 더 정확합니다.
  - 말로 설명: «0초에 손이 컵을 엎음, 화면 글 '이거 실화?', 2초에 …»처럼 초와 함께.
- **내 상품 자료**: 상품명, 핵심 장점 셋, 정확한 숫자(용량, 크기, 가격), 글자 없는 깨끗한 상품 사진 한 장.
- **AI 도구**(선택): claude.ai 에 Higgsfield 연결(그림 = Nano Banana Pro, Seedream / 영상 = Seedance, Kling / 목소리 = 보이스오버). ChatGPT 를 쓰면 콘티까지 만들고 지시문을 쓰는 생성 서비스에 붙여 넣습니다.

## 첫 한마디 예시

> 이 쇼츠 뜯어봐 줘. 스크립트 붙여 넣을게. 내 상품은 보온 텀블러(500ml, 12시간 보온)야. 같은 구조로 15초 콘티 짜 줘.

> 캡처 6장 올렸어. 0초, 1초, 2초, 4초, 8초, 12초야. 왜 잘 됐는지 표로 보여 줘.

## 절차

1. **내용 받기**: 스크립트, 캡처, 설명 가운데 받은 것으로 시간 순서를 맞춥니다. 빈 구간은 짐작하지 않고 «이 구간은 무엇이 보이나요?»라고 한 번 묻습니다.
2. **뜯어보기 표**를 채웁니다(아래 틀).
3. **«왜 눈을 붙잡나» 세 줄**로 요약합니다. 예: «첫 1초에 결과부터 보여 줌», «3초마다 화면이 바뀜», «7초에 반전».
4. **뼈대만 남깁니다**: 장면 그림, 대사 문장, 음악, 사람, 상표는 버리고 «초, 역할, 방식»만 남깁니다.
5. **첫 2초 훅을 한 줄로 먼저** 정합니다. «처음 2초에 무엇이 보이고 무슨 말이 나오나.» 이게 정해지면 나머지 컷을 나눕니다.
6. **콘티 표**를 내 상품으로 새로 씁니다(아래 틀). 대사는 전부 새로 씁니다.
7. 학생이 콘티를 보고 «좋아»라고 하면 **돈 확인** 뒤 시안 그림 → 영상 순서로 만듭니다.

## 뜯어보기 표

| 초 | 화면(무엇이 보이나) | 말(나레이션, 대사) | 화면 글(자막) | 역할 | 메모 |
|---|---|---|---|---|---|
| 0~1 | | | | 훅 | |
| 1~3 | | | | 훅 | |
| 3~7 | | | | 문제 / 리빌 | |
| 7~12 | | | | 반전 / 증거 | |
| 12~15 | | | | 결론 / 행동 | |

표 밑에 아래 다섯 칸을 따로 적습니다.

| 칸 | 볼 것 |
|---|---|
| 훅 세 겹 | 첫 1초의 그림, 말, 화면 글이 각각 무엇인가. 셋이 다 있나, 하나만 있나 |
| 컷 박자 | 몇 초마다 화면이 바뀌나(예: 평균 1.5초) |
| 자막 박자 | 자막이 몇 낱말마다 바뀌나, 한 번에 몇 줄인가 |
| 반전 자리 | 몇 초에 무엇이 뒤집히나(전/후, 예상 밖 결과, 가격 공개) |
| 끝 처리 | 첫 장면으로 되돌아 이어지나(다시 보기 유도), 행동 하나를 부탁하나(댓글, 저장, 보내기) |

## 콘티 표

| 컷 | 초 | 화면(그림 지시) | 움직임(영상 지시) | 자막 | 대사 |
|---|---|---|---|---|---|
| 1 훅 | 0~3 | 식탁 위 텀블러, 얼음이 가득 보이게 뚜껑이 열린 채 | 카메라가 천천히 다가감 | 아침 7시에 넣은 얼음 | 아침에 넣은 얼음, 지금 몇 시일까요? |
| 2 리빌 | 3~8 | 같은 식탁, 창밖이 저녁 노을 | 손이 텀블러를 기울여 얼음 소리 | 저녁 7시 | 열두 시간이 지났는데 아직 그대로예요 |
| 3 결론 | 8~13 | 상품 사진 그대로, 깨끗한 배경 | 느린 줌인 | 500ml · 12시간 보온 | 출근부터 퇴근까지, 한 번만 채우세요 |
| 4 행동 | 13~15 | 3번 끝 장면 유지 | 멈춤 | 링크는 고정 댓글에 | 필요한 분께 보내 주세요 |

- 위 예시는 가짜 상품입니다. 숫자는 반드시 내 상품의 실제 값으로 바꿉니다.
- **대사 길이**: 한국어 나레이션은 대략 1초에 4~5음절입니다. 말이 컷의 70% 정도만 차게 씁니다(5초 컷 = 15~18음절). 실제 길이는 목소리를 만든 뒤 재서 컷 초를 맞춥니다.
- **한 클립은 10초 이내**로 나눕니다. 길게 한 번에 만들면 장면이 무너지기 쉽습니다. 넘치면 영상을 늘리지 말고 대사를 줄입니다.

### 자주 쓰는 뼈대 셋

| 뼈대 | 구성 | 언제 |
|---|---|---|
| A 상품 단독 10초 | 1컷. 상품이 천천히 돌고 끝 2초에 핵심 부위로 다가감. 사람 없음 | 사진이 예쁜 상품, 가장 싸게 |
| B 이야기 15~20초 | 3컷. 훅 5초 / 리빌 7초 / 결론 6초 | 쓰기 전후가 분명한 상품 |
| C 합본 | B 뒤에 A 를 이어 붙임(A 는 6초로 자름) | B 의 끝을 상품 클로즈업으로 닫고 싶을 때 |

### 훅 설계 요령

- 신기한 장면은 호기심을 끌지만, 사고 싶은 마음은 «무슨 상품인지 바로 알 때» 생깁니다. **신기한 그림 2초 + 상품이 무엇인지 알려 주는 단서 3초**로 짭니다.
- 비유는 한 장면에 하나만 씁니다. 둘이 겹치면 보는 사람이 해석하느라 지칩니다.
- 끝에서 답을 끝까지 숨기는 «낚시»는 재생은 늘려도 구매는 줄입니다. 답은 주고, 첫 장면과 이어지게 끝내서 다시 보게 만듭니다.
- 참고: Wang & Liu (2022), Frontiers in Neuroscience, 초현실 광고 이미지와 소비자 반응 연구.

## 만들기

### 돈 확인(유료 생성 전에 꼭)

1. 만들 목록을 먼저 보여 줍니다. 예: «시안 그림 4장, 영상 5초 3개».
2. 쓰는 서비스에서 **한 번에 드는 크레딧이나 금액을 확인**하고 합계를 적어 보여 줍니다. 모르면 숫자를 짓지 않고 «서비스 화면에서 확인해 주세요»라고 말합니다.
3. 학생이 «만들어»라고 답한 뒤에만 생성합니다. 다시 만들기도 매번 같은 확인을 합니다.
4. 모르는 설정값(길이, 비율)을 «안 되면 거절되겠지» 하고 넣어 보지 않습니다. 받아들여지고 돈만 나가는 일이 있습니다. 도구 설명을 먼저 봅니다.

### 순서

| 순서 | 할 일 | 요령 |
|---|---|---|
| 1 | 대사 확정, 목소리 만들기 | 목소리를 먼저 만들어 실제 길이를 재고 컷 초를 정합니다 |
| 2 | 컷마다 시안 그림 2장 | 구도, 사람, 상품 모양을 여기서 끝냅니다. 그림은 영상보다 훨씬 쌉니다 |
| 3 | 학생이 컷마다 그림 한 장 고르기 | 고른 그림만 영상으로 갑니다 |
| 4 | 고른 그림을 첫 장면으로 영상 만들기 | 영상 지시문에는 «무엇이 움직이나»만 씁니다 |
| 5 | 내려받기 | 생성 결과 주소는 시간이 지나면 사라집니다. 나오면 바로 받아 둡니다 |
| 6 | 편집 | 자막, 음악, 목소리, 자르기는 편집 앱(캡컷 등)에서 얹습니다 |

### 지시문 요령

- **그림 지시**(무엇이 보이나: 사람, 상품, 구도, 빛, 배경)와 **움직임 지시**(카메라, 동작)를 나눠 씁니다. 그림 지시를 바꾸면 움직임 지시도 같이 고칩니다. 옛 문구가 남으면 옛 장면이 다시 나옵니다.
- **글자는 생성하지 않습니다.** 지시문 끝에 `no on-screen text, no captions, no logos, no watermark` 를 붙이고, 자막과 가격은 편집에서 얹습니다. 그래야 가격이 바뀌어도 영상을 다시 만들지 않습니다.
- **참조 사진은 글자 없는 상품 사진 한 장**이 가장 좋습니다. 상세페이지 배너처럼 문구가 큰 그림을 주면 모델이 엉뚱한 글자를 그립니다.
- **컷마다 같은 사람**이 나오게 하려면 앞 컷에서 고른 그림을 다음 컷의 참조로 줍니다. 같은 지시문만 다시 쓰면 매번 다른 사람이 나옵니다.
- **세로 9:16 에서 사람이 이상하게 나오면**(거꾸로, 화면을 꽉 채움) `Vertical 9:16, gravity is normal, the floor is always at the bottom, keep a medium distance` 를 더합니다.
- **한 컷에 변화 하나.** 과정보다 결과를 보여 줍니다. «하지 마»보다 «이렇게 된다»로 씁니다. 꼭 막아야 할 물리 실수는 `does NOT rotate, flip, tilt` 처럼 콕 집어 적습니다.
- **다가오는 동작이 잘 안 나오면** 반대 동작(멀어짐, 내려놓기)을 만들고 편집에서 거꾸로 재생합니다.
- **라벨, 성분표, 용량이 읽혀야 하는 상품**은 영상 모델이 글자를 바꿔 그립니다. 이럴 때는 실제 상품 사진에 느린 줌만 걸어 씁니다(0원, 글자가 원본 그대로).
- **시간이 오래 걸리거나 응답이 끊겨도** 실패가 아닐 수 있습니다. 바로 다시 보내지 말고 결과 목록을 먼저 확인합니다. 두 번 보내면 두 번 돈이 나갑니다.

### 마지막 3초(행동 부탁)는 올릴 곳마다 바꿉니다

| 올릴 곳 | 끝 문구 예 |
|---|---|
| 유튜브 쇼츠 | «링크는 고정 댓글에» |
| 인스타 릴스 | «필요한 분께 보내 주세요»(보내기가 많이 퍼지는 신호) |
| 네이버 숏클립 | 상품이 이미 붙어 있으니 가장 짧게 |

## 지키는 것

| 지킬 것 | 까닭 |
|---|---|
| **구조만 빌립니다.** 남의 영상 장면, 음악, 얼굴, 목소리, 상표, 대사 문장은 쓰지 않습니다. 대사는 내 상품으로 새로 씁니다 | 저작권, 초상권, 상표권 |
| 원본 영상을 내려받아 다시 올리거나 일부를 잘라 넣지 않습니다 | 저작권 |
| 음악은 직접 산 음원이나 플랫폼 무료 음원만 씁니다 | 저작권 |
| 숫자와 효능은 내 상품의 실제 자료에서만 가져옵니다. 건강, 의학 효과를 단정하지 않습니다 | 광고법 |
| AI 로 만든 사람을 «실제 사용자 후기»처럼 보이게 하지 않습니다 | 소비자를 속이는 광고 |
| **AI 로 만든 영상임을 표시합니다.** 유튜브는 업로드 때 «변경되거나 합성된 콘텐츠» 항목, 인스타는 «AI 정보» 표시를 켭니다. 화면 구석에 «AI 생성 영상» 글을 얹어도 좋습니다 | 플랫폼 규정, 국내 AI 표시 규정 |
| 실존 인물, 연예인을 닮게 만들지 않습니다 | 초상권 |
| 유료 생성은 매번 돈 확인 뒤에만 합니다 | 되돌릴 수 없음 |
