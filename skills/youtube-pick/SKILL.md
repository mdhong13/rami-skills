# 유튜브 영상 고르기

유튜브에는 «인공지능으로 ○○ 하는 법» 영상이 하루에도 수백 개 올라옵니다. 다 볼 수 없습니다. 이 스킬은 사람 대신 먼저 보고, **따라 할 영상 하나**를 고릅니다.

## 1. 먼저 묻는다 (한 번에 하나씩)

- 무엇을 하고 싶은지 (예: 상품 광고 영상 만들기, 상세페이지 쓰기)
- 지금 수준 (컴퓨터 설치를 해 본 적 있는지, 유료 구독을 할 생각이 있는지)
- 후보 영상 주소 (없으면 유튜브에서 무엇으로 찾을지 검색어 세 개를 먼저 지어 준다)

## 2. 영상을 읽는다

1. 주소로 영상 페이지를 읽는다. 제목, 올린 날짜, 길이, 설명란, 챕터, 댓글 위쪽을 본다.
2. 내용(자막)을 못 읽으면 사용자에게 부탁한다:
   «유튜브 영상 아래 설명란을 펼치고 [스크립트 표시]를 누른 뒤, 나온 글을 전부 복사해서 붙여 넣어 주세요.»
3. 화면을 봐야 알 수 있는 단계는 «화면 확인 필요»로 따로 적는다. 짐작으로 채우지 않는다.

## 3. 일곱 가지로 따진다

| 칸 | 묻는 것 | 낮은 점수 |
|---|---|---|
| 날짜 | 언제 올라왔나 | 6개월이 넘었다(인공지능 도구는 화면과 값이 자주 바뀐다) |
| 맞음 | 내가 하려는 일과 같은가 | 비슷해 보이지만 다른 일이다 |
| 단계 | 처음부터 끝까지 화면에 다 나오나 | «이건 다들 아시죠» 하고 건너뛴다 |
| 결과 | 만든 결과물을 실제로 보여 주나 | 말과 자막뿐이다 |
| 돈 | 어디서 얼마가 드는지 말하나 | 유료 구독, 크레딧을 숨기거나 맨 끝에 말한다 |
| 수준 | 내 수준으로 따라 할 수 있나 | 코딩, 설치가 많은데 설명이 없다 |
| 끝 | 영상이 무엇으로 끝나나 | 유료 강의, 단톡방, 전자책 판매로 끝난다(나쁜 건 아니지만 영상만으로는 안 될 수 있다) |

칸마다 상, 중, 하로 적고 까닭을 한 줄 단다.

## 4. 이렇게 답한다

1. **점수표** (영상마다 한 줄)
2. **고른 영상 하나**와 까닭 두 줄
3. **따라 할 단계 목록** (번호를 붙여서, 한 단계 한 줄. 영상 몇 분 몇 초에 나오는지 함께)
4. **미리 준비할 것** (가입할 곳, 드는 돈, 설치할 것)
5. **막힐 만한 곳** 두세 개와 막혔을 때 할 말
   (예: «화면을 캡처해서 올리고 "이 화면에서 다음에 뭘 눌러?"라고 물어보세요»)

## 지키는 것

- 영상에 없는 단계를 지어내지 않는다. 모르면 «영상에 안 나옴»이라고 쓴다.
- 고르기만 하고 결정은 사람이 한다.
- 돈이 드는 일은 맨 위에 적는다.
