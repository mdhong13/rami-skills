# 상품 하나로 SNS 한 벌

상품을 하나 올릴 때마다 인스타, 쓰레드, 유튜브에 따로 글을 쓰기는 힘듭니다. 이 스킬은 **상품 사실표 한 장**으로 세 채널 글을 한 번에 씁니다. 그림과 영상은 만들지 않고, **무엇을 찍고 어떤 사진을 고를지** 지시만 붙입니다. 실제 그림은 내 도구(캔바, 휴대폰, 힉스필드 등)로 만듭니다.

## 쓰시는 분께 말하는 법 (먼저 읽고 지킵니다)

이 설명서를 쓰는 분은 스마트스토어, 쿠팡, 자사몰에서 물건을 파는 사장님입니다. 막 시작한 분도 있고, 오래 장사했지만 컴퓨터와 인공지능은 익숙하지 않은 분도 있습니다.

- 쉬운 우리말로 말합니다. 프롬프트, 참조 이미지, 크레딧, 썸네일 같은 말은 처음 쓸 때 괄호로 풉니다. 예: 크레딧(그림, 영상을 만들 때 쓰는 충전 포인트).
- 한 번에 하나만 묻습니다. 고를 것이 있으면 추천 하나와 까닭을 먼저 말합니다.
- 자료가 모자라면 준비물 표를 통째로 보여 주지 않습니다. 가장 먼저 필요한 것 하나만 묻고, 받으면 다음 하나를 묻습니다. 예: «어떤 물건인가요? 상품 페이지나 포장 상자를 사진으로 찍어 올려 주셔도 됩니다.»
- 아래 절차의 표와 점검표는 인공지능이 속으로 쓰는 도구입니다. 사용자에게는 결과만 짧게, 바로 복사해 쓸 수 있는 꼴로 보여 줍니다.
- 영어 지시문은 인공지능이 알아서 씁니다. 사용자에게는 무엇을 그릴지 한국어 한두 줄로만 보여 주고 확인받습니다.
- 사용자가 무엇을 줘야 할지 모르면 할 수 있는 방법을 하나씩 알려 줍니다. 예: 휴대폰으로 상품 사진 찍기, 화면 캡처해 올리기, 글을 길게 눌러 복사하기.
- 돈이 드는 일은 «얼마쯤 듭니다. 할까요?»처럼 쉬운 말로 먼저 묻고, 좋다고 할 때만 합니다.
- 사용자가 헤매도 탓하지 않습니다. 다음에 누를 곳이나 할 말을 구체적으로 알려 줍니다.

## 1. 무엇을 하나

| 결과물 | 안에 든 것 | 올리는 곳 |
|---|---|---|
| 카드뉴스 | 5~7장 문구, 장마다 사진 지시, 캡션, 해시태그 3~5개 | 인스타 피드 |
| 쓰레드 글 | 짧은 첫 줄, 본문, 첫 답글, 사진 1~4장 지시, 주제 태그 1개 | 쓰레드 |
| 쇼츠 대본 | 20~30초 초 단위 표(화면, 자막, 대사, 소리), 제목, 설명란 | 유튜브 쇼츠 (인스타 릴스에도 같은 영상) |

## 2. 준비물

| 준비물 | 없으면 |
|---|---|
| 상세페이지 글 전부(복사해서 붙여 넣기) 또는 상품 주소 | 꼭 필요합니다. 없으면 시작하지 않습니다 |
| 정확한 상품명, 판매가, 옵션표 | 비워 두면 그 자리는 숫자 없이 씁니다 |
| 실물 사진 5~10장 | 휴대폰으로 찍어도 됩니다. 카드뉴스는 사진이 있어야 합니다 |
| 실물이 움직이는 영상(사용, 조립, 언박싱) | 쇼츠는 휴대폰으로 10~20초 몇 개 찍는 것부터 권합니다 |
| 손님이 자주 묻는 말, 실제 후기 원문 | 없으면 «묻는 말» 장을 일반적인 궁금증으로 씁니다 |
| 광고, 협찬, 체험단 여부 | 기본은 «내 가게 내 상품»으로 봅니다 |

## 3. 첫 한마디 예시

```
캠핑 화로 상세페이지 붙여 넣을게. 이걸로 SNS 한 벌 만들어 줘.
```
```
카드뉴스만 만들어 줘. 사진은 6장 있어. (사진 올림)
```
```
이 영상으로 쇼츠 대본 써 줘. 25초, 내 목소리로 읽을 거야.
```
```
쓰레드 글 세 가지 버전으로. 첫 줄이 다 달라야 해.
```

## 4. 절차

1. **사실표를 만듭니다.** 상세페이지에서 상품명, 가격, 옵션, 크기와 무게 같은 숫자, 쓰는 장면, 묻는 말을 뽑아 표로 보여 줍니다. 원문에 없는 칸은 비워 둡니다. 사용자가 «맞아»라고 하면 다음으로 갑니다.
2. **포인트를 3~7개 뽑습니다.** 하나가 한 문장 주장 + 근거(사실표의 어느 줄) + 누구에게 좋은지입니다. «이것 하나만 본 사람에게도 쓸모가 있나»로 순서를 매기고 1등을 중심에 둡니다.
3. **첫 줄(고리) 후보를 다섯 개 씁니다.** 서로 다른 꼴로 쓰고, 추천 하나를 까닭 한 줄과 함께 고릅니다. 다섯 개가 같은 말로 시작하면 다시 씁니다.
4. **채널마다 새로 씁니다.** 단계 설명은 카드뉴스, 장면 이야기는 쓰레드, 보여 줘야 아는 것은 쇼츠에 줍니다. 한 채널 글을 다른 채널에 복사해 붙이지 않습니다.
5. **사진과 영상 지시를 붙입니다.** 장마다, 컷마다 «무엇이 보이는 사진(영상)», «어디를 크게», «글이 놓일 자리»를 적습니다.
6. **9절 점검표로 스스로 검사**하고, 걸린 줄을 고친 뒤 보여 줍니다.
7. **올리는 날을 나눕니다.** 한 상품 글 셋을 하루에 몰아 올리지 않고 하루 이상 띄우기를 권합니다.

**첫 줄(고리) 꼴** (상품 이름으로 열지 않고, 물음을 남긴 뒤 몇 초 안에 답합니다)

| 꼴 | 캠핑 화로라면 |
|---|---|
| 손님 처지의 질문 | «텐트 안에서 밤새 손 비비고 계셨죠?» |
| 엇갈린 신호 | «작아 보이는데, 이거 하나로 저녁이 끝납니다» |
| 결과 먼저 | 첫 화면에 불이 확 붙은 모습 + «불 붙이는 데 {점화 시간}» |
| 틀린 믿음 깨기 | «화로는 다 무겁다고요? 이건 {무게}» |
| 값 먼저 | «{판매가}원에 이게 됩니다» |
| 받는 물음 | «이거 보면 꼭 묻는 게 있어요» |
| 상황 한 줄 | «영하 캠핑 첫날 밤, 이 장면 아시죠» |

고리 점검: 이 줄에서 손이 멈추나? 뒤에서 답할 물음이 생기나? 다른 상품 글에 그대로 붙여도 말이 되면 실패입니다. 약속한 답은 반드시 뒤에서 줍니다.

## 5. 카드뉴스 규칙

- **판형**: 세로 4:5(1080×1350). 피드에서 자리를 가장 크게 차지합니다.
- **장 수**: 5~7장. 채우려고 늘리지 않습니다.
- **1장 = 썸네일**: 뒤에 장이 더 있는 줄 모르는 사람에게 혼자 보입니다. 이 장만 올려도 손이 멈출지로 시험합니다. 굵은 제목 한 줄(여덟 낱말 안쪽) + 부제 한 줄. **누구 얘기인지는 보이고, 답은 안 보이게** 씁니다. 첫 장은 몸통을 다 쓴 뒤 마지막에 씁니다.
- **2장 = 손님이 묻는 말**: 불편이나 궁금증을 한두 문장으로 짚어 본론으로 잇습니다.
- **장마다 한 생각**: 설명이 두 문장을 넘으면 두 장으로 나눕니다.
- **약속한 개수**: 첫 장에 «세 가지»라고 했으면 정확히 세 개를 줍니다.
- **같은 틀**: 안쪽 장은 배치, 글자 크기, 색을 같게 둡니다. 글자는 크게(50대 손님도 읽게).
- **마지막 장 = 행동 하나**: 한 줄 요약 + «프로필 링크에서 보기», «저장해 두기», «필요한 분께 보내기» 중 **하나만**.
- **캡션**: 첫 장을 되풀이하지 말고 다른 각도로 엽니다. 앞 두세 줄 안에서 «더 보기»를 누르게 씁니다. 캡션 속 주소는 눌리지 않으니 «프로필 링크»로 안내합니다. 검색될 낱말은 캡션에 넣습니다.
- **해시태그 3~5개**. 많이 달수록 좋지 않습니다.
- **대체 글**: 장마다 사진 설명을 한 줄 씁니다(인스타 고급 설정).
- **사진 고르기**: 실물 사진을 씁니다. 다른 회사 상표가 보이는 사진, 흐린 사진, 외국어 글자가 비치는 사진, 효능을 그림으로 말하는 사진(세균, 병원 그림 등)은 뺍니다. 사진 위에 글을 얹으면 어두운 덧칠을 깔아 글이 읽히게 합니다.
- **옵션에 없는 것은 보여 주지도 말하지도 않습니다.** 사진에 기본 구성이 아닌 부품이 찍혀 있으면 그 사진을 빼거나 잘라 냅니다.
- AI 그림(힉스필드 등)을 쓸 때는 실물 사진을 참고로 넣어 만들고, 완성본을 실물과 대조합니다(모양, 색, 부품 수). 다르면 쓰지 않습니다.

## 6. 쓰레드 규칙

- **첫 줄은 한두 줄로 아주 짧게.** 펼치기 전에는 처음 몇 줄만 보입니다. 공감, 장면, 전후 비교가 잘 먹힙니다.
- **말씨는 친구에게 문자 보내듯.** 매끈한 회사 말투는 오히려 광고로 읽힙니다. 설명은 해요체, 감탄 한마디는 편하게 섞어도 됩니다.
- **길이**: 한 글 500자 안, 짧은 문단 1~3개. 길어지면 답글로 이어 씁니다. 이어지는 글 하나에 한 생각.
- **인스타 캡션을 옮겨 붙이지 않습니다.** 쓰레드 말씨로 새로 씁니다.
- **사진 1~4장**: 글이 사진을 그대로 설명하지 말고, 사진에 없는 뜻을 더합니다.
- **주제 태그 1개.** 쓰레드는 해시태그로 크는 곳이 아닙니다.
- **링크**: 경험상 본문보다 **첫 답글**이나 프로필에 두는 편이 반응이 나았습니다. 공식 규칙은 아니니 내 계정에서 둘 다 해 보고 고릅니다.
- **올린 뒤 30분**은 자리에 있으면서 댓글에 답합니다.
- 배송, 교환처럼 긴 조건은 상세페이지에 맡기고 SNS 글은 가격과 링크 안내에서 끝냅니다. 단 없는 조건(«빠른 배송» 등)을 지어 쓰지 않습니다.

## 7. 쇼츠 대본 규칙

- **판형과 길이**: 세로 9:16(1080×1920), 20~30초로 시작합니다. 길이는 정답이 없고, 유튜브 스튜디오의 «넘기지 않고 본 비율»을 보며 늘리고 줄입니다.
- **첫 화면이 고리입니다.** 1초 안에 걸어야 합니다. 로고, 인사, 무음으로 열지 않습니다. 화면(그림) + 자막 + 목소리가 같은 말을 합니다. 소리를 끄고 첫 3초만 봐도 무슨 얘기인지 보여야 합니다.
- **답은 빨리**: 3~6초 안에 물건을 보여 주고, «그런데»로 새 물음을 하나 잇습니다.
- **한 가지 장점 + 증거 장면 + 가격.** 기능을 다 늘어놓는 40초는 지는 구조입니다.
- **실물 영상 컷을 고릅니다.** 사진 넘기기 위에 같은 말투 나레이션만 입힌 영상은 유튜브가 «진정성 없는 콘텐츠»의 예로 든 모양과 닮았습니다. 손으로 짚고 쓰는 실물 컷이 가장 낫습니다.
- **남의 영상**: 남의 쇼츠는 편집 꼴만 배우고 장면, 대본, 음악은 가져오지 않습니다. 제조사나 도매처에서 받은 상품 영상은 써도 되는지 먼저 확인합니다. 다른 앱 로고(워터마크)가 박힌 영상은 인스타가 추천하지 않으니, 내가 찍은 원본을 올립니다.
- **컷 고르기**: 다른 회사 상표가 새겨진 컷, 옵션에 없는 부품이 나오는 컷은 뺍니다. 끝 컷은 첫 컷과 같은 모습으로 두어 반복 재생이 자연스럽게 합니다.
- **자막은 무조건**: 소리 끄고 보는 사람이 많습니다. 한 화면 두 줄까지, 줄은 짧게, 굵은 고딕 흰 글자에 검은 테두리, 핵심 낱말만 다른 색. 자막은 화면 가운데 가까이 둡니다.
- **자막 안전 영역**: 1080×1920 기준 **위 220px, 아래 500px, 좌우 180px**은 비웁니다. 글과 상품 핵심은 가운데 720×1200 띠 안에 둡니다(앱 버튼과 설명 글에 가리지 않게). 앱이 바뀌면 다시 확인합니다.
- **대사**: 화면 글자는 짧게, 말은 이어지는 문장으로 씁니다. AI 목소리로 읽힐 때는 숫자를 한글로 풀어 쓰고(예: 2.5kg → 이 점 오 킬로그램) 한 번 들어 봅니다. 끝 문장이 너무 짧으면 끊겨 들리니 조금 길게 맺습니다.
- **끝 3~5초에 행동 하나**(말 + 자막). 음악은 마지막에 서서히 줄입니다. 뚝 끊기면 고장 난 것처럼 보입니다. 구독, 좋아요 부탁보다 첫 줄을 받는 맺음 한 줄이 낫습니다.
- **상품 자체는 AI 영상으로 만들지 않습니다.** 모양이 틀어집니다. AI는 배경, 분위기 컷 정도에 씁니다. 실제처럼 보이는 AI 사람이나 장면을 넣었으면 유튜브 올릴 때 «변경되거나 합성된 콘텐츠»에 «예»를 고릅니다.
- **제목**: 앞 60~70자 안에 핵심 낱말, 끝에 #shorts. 설명란은 짧게, 해시태그 3개 이하.

**형식 셋** (먼저 1을, 반응을 본 뒤 2와 3을 시험합니다)

| | 1 문제에서 해결로 | 2 가격 먼저 + 소리 | 3 공감 상황극 + 실물 |
|---|---|---|---|
| 첫 화면 | 불편한 장면 | 큰 가격 글자 + 실물 소리 | 사람 얼굴과 공감 한 줄 |
| 재료 | 사용 장면 영상 | 실물 클로즈업과 원래 소리 | 사람 컷 1~2개 + 실물 컷 |
| 맞는 곳 | 쇼츠 | 릴스(소리 켜고 보는 곳) | 둘 다, 공유를 노릴 때 |

## 8. 결과물 꼴 (예시 틀: 캠핑 화로)

`{ }` 자리는 사실표 값으로만 채웁니다. 사실표에 없으면 그 문장을 숫자 없이 바꿉니다.

**카드뉴스**

| 장 | 큰 글 / 작은 글 | 사진 지시 |
|---|---|---|
| 1 | 텐트 안 밤 추위, 이걸로 끝냈습니다 / 작은데 저녁까지 됩니다 | 불 붙은 화로 정면, 화면 가득. 글은 위쪽 어두운 자리 |
| 2 | 밤에 손 시려서 일찍 들어가셨죠? / 추위 때문에 캠핑 접는 분 많습니다 | 저녁 텐트 바깥, 사람 손 |
| 3 | 불은 {점화 방식}으로 / 붙이는 데 {점화 시간} | 불 붙이는 손 클로즈업 |
| 4 | 위에서 {조리 예} / 물 끓이기까지 한 자리에서 | 화로 위 주전자 |
| 5 | 접으면 {접은 크기} / 무게 {무게} | 접은 모습 + 손 크기 비교 |
| 6 | 기본 구성 {구성} / {판매가}원 | 구성품을 바닥에 펼친 위에서 찍은 사진 |
| 7 | 겨울 캠핑 준비, 저장해 두세요 / 프로필 링크에서 보기 | 1장과 같은 불꽃 사진 |

캡션: «올겨울 첫 캠핑 날짜 잡으셨어요? 밤 추위가 걱정이면 4장부터 보세요. … 자세한 구성은 프로필 링크에 있습니다.» + 해시태그 4개

**쓰레드**

```
첫 줄: 캠핑 가서 제일 먼저 꺼지는 건 체력이 아니라 손이더라고요.
본문: 그래서 요즘 저녁엔 작은 화로 하나 놓고 앉아 있어요. 접으면 {접은 크기}라 트렁크 구석에 들어갑니다. (사진 2장: 불꽃, 접은 모습)
첫 답글: 구성이랑 가격은 여기 있어요 → {판매 주소}
주제 태그: 캠핑
```

**쇼츠 대본 (25초)**

| 초 | 화면 | 자막(가운데 띠) | 대사 / 소리 |
|---|---|---|---|
| 0~2 | 서리 낀 텐트, 입김 | 영하 캠핑, 밤이 문제죠 | «영하 캠핑 가면 밤이 제일 길잖아요.» / 바람 |
| 2~6 | 불 붙는 순간 클로즈업 | 그런데 {점화 시간}이면 | «그런데 이거 하나면 금방 따뜻해집니다.» / 타닥 |
| 6~14 | 화로 위 주전자 김 | 물 끓이기까지 한 자리에서 | «위에서 물도 끓이고 저녁도 해결해요.» |
| 14~20 | 접는 손, 트렁크에 넣기 | 접으면 {접은 크기} | «다 쓰면 접어서 트렁크 구석에 넣으면 끝입니다.» |
| 20~25 | 가격 글자 → 첫 장면과 같은 텐트 | {판매가}원, 프로필 링크 | «자세한 건 프로필 링크에서 보세요.» / 바람(반복) |

제목: «영하 캠핑, 밤이 짧아지는 법 | 캠핑 화로 #shorts», 설명란 두 줄 + 해시태그 3개

## 9. 지키는 것 (점검표)

| 점검 | 이렇게 |
|---|---|
| 숫자 | 가격, 크기, 시간, 판매량은 사실표에 있는 것만. 없으면 숫자 없는 문장으로. 지어낸 통계(«열 명 중 여덟»), «○○명이 선택» 쓰지 않음 |
| 효능 | 의학, 건강, 미용 효과를 단정하지 않음(«병이 낫는», «살이 빠지는»). 식품, 화장품, 건강용품은 광고 규정이 더 엄하니 따로 확인 |
| 후기 | 가짜 후기, 지어낸 사용기 쓰지 않음. 후기를 인용하면 실제 원문 그대로. AI 인물이 «제가 써 봤는데»라고 말하게 하지 않음 |
| 옵션 | 옵션표에 없는 부품, 색, 기능은 글에도 사진에도 넣지 않음 |
| 내 말로 | «판매자가 소개하길», «상세페이지에 따르면»처럼 남의 말을 옮기는 꼴 대신 내가 파는 사람으로서 사실을 바로 말함 |
| 마감, 한정 | 진짜 기간, 진짜 혜택일 때만. «재고 얼마 안 남음»은 근거 있을 때만 |
| 비교 | 사실만 비교하고 다른 상품을 깎아내리지 않음 |
| 광고 표시 | 협찬, 체험단, 대가를 주고 남의 채널에 올리게 할 때, 파트너스 링크로 수수료를 받을 때는 제목이나 첫 부분에 «광고», «협찬»을 밝힘. 유튜브는 «유료 프로모션» 체크 |
| AI 인물 | 공정위 추천보증 심사지침(2026-06-01 시행)은 AI로 만든 가상 인물이 상품을 추천하면 가상 인물임을 표시하게 합니다. 가상 인물이 «써 봤다»고 말하게 하지도 않습니다. 쓰기 전에 최신 지침을 확인 |
| AI 티 문장 | «그냥 ○○가 아니라 ○○입니다» 뒤집기, «혁신적인», «완벽한», «게임 체인저» 같은 닳은 말, «끝까지 보시면 놀라실 거예요» 빈 예고, 줄마다 이모지, 최상급(«최고», «1위»)을 쓰지 않고 이 상품에만 있는 사실 하나로 바꿈 |
| 사람이 올림 | 글은 초안입니다. 사람이 읽고 고치고 직접 올립니다. 자동 게시하지 않음 |

**올린 뒤**: 좋아요보다 저장, 보내기, 끝까지 넘김을 봅니다. 한 번에 하나만 바꿔 시험합니다(같은 그림, 다른 첫 줄). 조회가 계속 0이면 글보다 계정 상태(인스타 설정의 «계정 상태»)를 먼저 봅니다. 조회만 많고 판매가 없으면 이긴 틀이 아닙니다.
