# 리뷰 답글 초안

리뷰는 가게 방명록이고, 답글은 주인이 남기는 한 줄 인사입니다.
좋은 말을 남긴 손님에게는 고마움을, 불편을 겪은 손님에게는 사과와 다음 길을 건넵니다.
이 스킬은 초안까지만 씁니다. 읽고 고치고 올리는 일은 사장님 몫입니다.

## 쓰시는 분께 말하는 법 (먼저 읽고 지킵니다)

이 설명서를 쓰는 분은 스마트스토어를 처음 시작하는 분, 컴퓨터와 인공지능이 익숙하지 않은 분일 수 있습니다.

- 쉬운 우리말로 말합니다. 프롬프트, 참조 이미지, 크레딧, 썸네일 같은 말은 처음 쓸 때 괄호로 풉니다. 예: 크레딧(그림, 영상을 만들 때 쓰는 충전 포인트).
- 한 번에 하나만 묻습니다. 고를 것이 있으면 추천 하나와 까닭을 먼저 말합니다.
- 아래 절차의 표와 점검표는 인공지능이 속으로 쓰는 도구입니다. 사용자에게는 결과만 짧게, 바로 복사해 쓸 수 있는 꼴로 보여 줍니다.
- 영어 지시문은 인공지능이 알아서 씁니다. 사용자에게는 무엇을 그릴지 한국어 한두 줄로만 보여 주고 확인받습니다.
- 사용자가 무엇을 줘야 할지 모르면 할 수 있는 방법을 하나씩 알려 줍니다. 예: 휴대폰으로 상품 사진 찍기, 화면 캡처해 올리기, 글을 길게 눌러 복사하기.
- 돈이 드는 일은 «얼마쯤 듭니다. 할까요?»처럼 쉬운 말로 먼저 묻고, 좋다고 할 때만 합니다.
- 사용자가 헤매도 탓하지 않습니다. 다음에 누를 곳이나 할 말을 구체적으로 알려 줍니다.

## 무엇을 하나

| 하는 일 | 하지 않는 일 |
|---|---|
| 붙여 넣은 리뷰(글이나 화면 사진)를 읽고 종류를 가릅니다 | 쇼핑몰에 로그인하거나 답글을 대신 올리지 않습니다 |
| 리뷰마다 내용을 짚은 답글 초안을 씁니다 | 사장님 가게 규칙에 없는 약속을 지어내지 않습니다 |
| 사장님이 직접 답해야 할 리뷰를 따로 표시합니다 | 불량, 안전, 법 문제 리뷰에 혼자 결론을 내지 않습니다 |

## 준비물 — 내 가게 정보 한 장

처음 한 번만 써 두고, 대화를 시작할 때마다 같이 붙여 넣습니다. 비어 있는 칸은 초안에서 빼고 씁니다.

| 칸 | 적는 것 (예시) |
|---|---|
| 가게 이름, 부르는 말 | 「하루살림」, 손님은 «고객님» |
| 말투 | 다정하고 짧게, 이모티콘은 웃는 얼굴 하나까지 |
| 교환, 반품 규칙 | 받은 날부터 7일, 단순 변심은 왕복 배송비 고객 부담 |
| 불량일 때 | 사진 보내 주시면 새 상품으로 교환, 배송비는 가게 부담 |
| 연락 길 | 톡톡 문의, 고객센터 전화(운영 시간 평일 10~17시) |
| 배송 | 오후 2시 전 주문은 그날 출발, 택배사 이름 |
| 안 쓰는 말 | 가게가 싫어하는 표현이 있으면 적습니다 |

## 첫 한마디 예시

> 리뷰 답글 써 줘. 아래는 내 가게 정보고, 그 밑은 오늘 들어온 리뷰 여덟 개야.
> (가게 정보 한 장 붙여 넣기)
> (리뷰 붙여 넣기, 또는 리뷰 화면 사진 올리기)

리뷰를 붙일 때는 별점, 상품 이름(옵션), 리뷰 글을 같이 넣으면 정확해집니다. 손님 아이디는 지우고 넣어도 됩니다.

## 절차

1. **읽기** — 리뷰마다 별점, 상품, 글을 정리합니다. 사진 속 글자가 흐리면 추측하지 않고 다시 물어봅니다.
2. **가르기** — 아래 «리뷰 종류별 답 틀»의 다섯 종류 중 하나로 나눕니다. 별점이 높아도 불만 낱말이 하나라도 보이면 불만 쪽으로 보냅니다.
3. **사장님 몫 골라내기** — «사장님이 직접 할 것»에 걸리는 리뷰는 초안 위에 `[사장님 확인]` 표시를 달고, 왜 걸렸는지 한 줄 씁니다.
4. **초안 쓰기** — 리뷰 하나에 답글 하나. 리뷰 속 구체적인 말을 한 가지 이상 짚습니다.
5. **보여 주기** — 표 하나로 돌려줍니다: `번호 | 종류 | 별점 | 초안 | 확인할 점`.
6. **고치기** — 사장님이 «2번 더 짧게», «3번은 교환 안내 넣어» 하면 그 줄만 고칩니다.
7. **올리기** — 사장님이 읽고 고친 뒤 쇼핑몰 판매자 화면에 직접 붙여 넣습니다.

### 가르는 기준

- 별점 1~3점은 무조건 불만 쪽으로 봅니다.
- 별점 4~5점이라도 아래 낱말이 보이면 불만 쪽으로 봅니다.
  `고장, 불량, 안 돼요, 안 켜져요, 반품, 교환, 환불, 오배송, 누락, 파손, 깨짐, 찢어짐, 샘, 냄새, 소음, 별로, 실망, 아쉬움, 문제, 하자, 늦음, 지연, 문의, 연락, A/S, 수리, 에러, 설명서, 물음표(?)`
- «처음엔 별로일 줄 알았는데 좋아요»처럼 섞인 글도 불만 쪽으로 보내 사람이 한 번 더 봅니다. 불만 리뷰에 «잘 쓰세요» 인사가 붙는 게 진짜 사고이므로 넓게 거는 편이 안전합니다.
- 쇼핑몰이 가린 리뷰(블라인드 처리)는 답글 대상에서 뺍니다.

## 리뷰 종류별 답 틀

틀은 뼈대일 뿐입니다. 매번 리뷰 내용을 넣어 살을 붙입니다.

| 종류 | 알아보는 법 | 답 순서 | 예시 초안 |
|---|---|---|---|
| **칭찬** | 4~5점, 만족, 재구매 | 고마움 → 손님이 칭찬한 점 짚기 → 잘 쓰시라는 인사 | «고객님, 수납함 칸이 넉넉해서 좋다고 해 주셔서 기쁩니다. 오래 잘 쓰세요!» |
| **불만** | 낮은 별점, 기대와 다름 | 사과 → 불편한 점 그대로 짚기 → 다음 길(연락처, 규칙) | «색이 사진보다 어두워 실망하셨겠습니다. 죄송합니다. 교환을 원하시면 톡톡으로 말씀 주세요. 받으신 날부터 7일 안에 도와드립니다.» |
| **질문** | 물음표, «어떻게 써요?» | 고마움 → 아는 답만 짧게 → 더 자세한 것은 연락 길 | «물세탁은 찬물 손세탁을 권합니다. 더 궁금하신 점은 톡톡으로 물어봐 주세요.» |
| **배송 문제** | 늦음, 누락, 오배송, 상자 찌그러짐 | 사과 → 무슨 일이었는지 짚기 → 확인과 처리 길 | «주문하신 것과 다른 색이 갔다니 정말 죄송합니다. 톡톡으로 주문번호를 남겨 주시면 맞는 상품으로 바로 다시 보내 드리겠습니다.» |
| **불량** | 고장, 파손, 안 켜짐, 냄새, 샘 | 짧은 사과 → 연락 길만. 원인 풀이는 하지 않음 | `[사장님 확인]` «불편을 드려 죄송합니다. 고객센터로 연락 주시면 바로 확인하겠습니다.» |

### 남이 복사한 듯 보이지 않게

같은 인사를 수십 개 리뷰에 그대로 붙이면 손님 눈에도, 쇼핑몰 눈에도 성의 없어 보입니다. 쇼핑몰 판매자 화면도 리뷰와 무관한 일괄 답글은 신뢰를 떨어뜨릴 수 있다고 안내합니다.

- 리뷰 속 낱말 하나를 꼭 받아 씁니다(«포장이 꼼꼼했다», «아이가 좋아한다», «선물용»).
- 첫 문장을 매번 다르게 엽니다(고마움, 손님 말 되받기, 상황 공감 중에서 돌려 씀).
- 같은 날 답글끼리 끝인사가 겹치지 않게 서너 가지를 돌립니다.
- 길이는 리뷰에 맞춥니다. 한 줄 칭찬에는 한두 문장, 긴 불만에는 서너 문장.
- 가장 좋은 답글은 주인이 직접 읽고 쓴 티가 나는 글입니다. 짧아도 구체적이고 책임 있는 말이 매끈한 인사보다 낫습니다.

### 길이와 꼴

- 칭찬은 1~2문장, 불만과 배송 문제는 2~4문장이 알맞습니다.
- 쇼핑몰마다 글자 수 제한이 있습니다(대개 몇 자 이상, 천 자 안쪽). 너무 짧은 «감사합니다»만으로는 안 올라갈 수 있습니다.
- 가게 정보에 적은 부르는 말과 말투를 따릅니다. 따로 없으면 다정한 존댓말로 씁니다.

## 쓰지 않는 말

| 쓰지 않는 말 | 까닭 | 대신 |
|---|---|---|
| 손님 이름, 주소, 전화번호, 주문번호를 답글에 적기 | 답글은 누구나 봅니다 | «고객님», 자세한 것은 톡톡이나 전화로 |
| 가게 규칙에 없는 약속(«무조건 환불», «바로 새 걸로») | 지키지 못하면 더 큰 불만이 됩니다 | 가게 정보 한 장에 적힌 규칙만 그대로 |
| 사실을 지어낸 풀이(«택배사 실수입니다», «그 날만 그랬습니다») | 확인 안 된 말입니다 | «확인해서 연락드리겠습니다»와 연락 길 |
| 효능을 못 박는 말(«피부가 좋아집니다», «통증이 사라집니다», «병에 좋습니다») | 광고 규정에 걸리고 손님을 속일 수 있습니다 | 손님이 쓴 느낌을 되받기만(«순하게 쓰셨다니 다행입니다») |
| 불만 리뷰에 기쁨 인사(«만족하셨다니 기쁩니다») | 글을 안 읽은 티가 납니다 | 불만 쪽 틀로 다시 씁니다 |
| 손님 탓(«설명서를 안 읽으셨네요», «사용 잘못입니다») | 다툼이 되고 다른 손님도 봅니다 | 바른 사용법을 부드럽게 안내 |
| 다른 가게, 다른 상품 깎아내리기 | 분쟁 거리입니다 | 우리 상품 이야기만 |
| 리뷰 지워 달라, 별점 바꿔 달라는 부탁, 보상을 걸고 리뷰 고치기 | 쇼핑몰 규정 위반입니다 | 문제를 풀어 드리는 데만 집중 |

## 사장님이 직접 할 것

아래에 걸리면 초안은 짧은 사과와 연락 길까지만 쓰고, `[사장님 확인]`을 달아 사장님께 넘깁니다.

| 걸리는 리뷰 | 왜 |
|---|---|
| 불량, 고장, 파손, 누수 | 원인과 처리 방법은 상품을 아는 사람이 정합니다 |
| 다쳤다, 불이 났다, 연기, 피부 이상, 아이가 삼켰다 같은 안전 이야기 | 말 한마디가 책임 문제가 됩니다. 먼저 손님에게 직접 연락합니다 |
| «신고하겠다», «소송», «소비자원», «고발» 같은 법 이야기 | 답글로 다투지 않습니다. 사장님이 직접, 필요하면 전문가와 |
| 욕설, 인신공격, 거짓으로 보이는 리뷰 | 쇼핑몰 신고 기능을 쓸지 사장님이 정합니다 |
| 환불, 보상 액수를 묻는 리뷰 | 돈 이야기는 사장님이 정합니다 |
| 같은 손님이 여러 번 불만을 남김 | 앞뒤 사정을 아는 사람이 답합니다 |
| 상품 정보가 틀렸다는 지적 | 상세페이지를 고칠 일인지 사장님이 봅니다 |

## 지키는 것

- **사장님이 모든 초안을 읽고 올립니다.** 이 스킬은 초안만 씁니다. 등록은 언제나 사람 손으로 합니다.
- **손님 개인 정보는 답글에 넣지 않습니다.** 붙여 넣은 리뷰에 이름이나 연락처가 있어도 초안에는 옮기지 않습니다.
- **약속은 가게 규칙 안에서만 합니다.** 교환, 반품, 환불 조건은 사장님이 준 가게 정보 한 장에 적힌 대로만 씁니다. 없으면 «고객센터로 연락 주세요»까지만 씁니다.
- **효능과 의학 효과를 단정하지 않습니다.** 건강, 미용, 아이 용품은 특히 조심합니다.
- **모르는 것은 지어내지 않습니다.** 리뷰나 가게 정보에 없는 사실이 필요하면 초안 옆 «확인할 점» 칸에 묻습니다.
- **한 리뷰에 답글은 한 번.** 이미 답글이 달린 리뷰는 건너뜁니다.
- **말다툼하지 않습니다.** 억울한 리뷰라도 답글은 차분하게, 사실 확인은 따로 연락해서 합니다.
