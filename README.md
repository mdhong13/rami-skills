# rami-skills

쇼핑몰 사장님이 인공지능(클로드, 챗GPT)에게 바로 줄 수 있는 **업무 설명서** 모음입니다.

강의 «인공지능과 장사, 그리고 쇼핑라이브»에서 나눠 드리는 자료입니다. 저희 회사가 몇 달 동안 실제로 쓰면서 고친 방법을, 누구나 쓸 수 있게 다시 썼습니다. 돈 받고 파는 것이 아닙니다. 마음껏 쓰고, 고치고, 나누세요.

## 스킬이 뭔가요

인공지능은 천재지만, 새 대화창을 열 때마다 어제 일을 다 잊습니다.
**스킬은 인공지능이 일을 시작하기 전에 읽는 설명서**입니다. 설명서를 한 번 넣어 두면, 매번 처음부터 설명하지 않아도 같은 순서와 같은 기준으로 일합니다.

## 설치하는 법

### 클로드 앱, 웹(claude.ai)

1. 위 표에서 원하는 스킬을 고르고, [dist](dist) 폴더에서 같은 이름의 `.zip` 파일을 내려받습니다.
2. 클로드에서 **설정 → 기능**으로 갑니다.
3. **스킬** 칸에서 «스킬 올리기»를 누르고 `.zip` 파일을 고릅니다.
4. 새 대화에서 평소처럼 말하면 됩니다. 예: «이 상품 상세페이지 기획해 줘.»

스킬 칸이 안 보이면, 같은 화면에서 «코드 실행과 파일 만들기»가 켜져 있는지 확인하세요.

### 클로드 코드(Claude Code)

`skills` 폴더 안의 스킬 폴더를 통째로 `~/.claude/skills/` 에 복사합니다.

### 챗GPT

스킬 폴더 안의 `SKILL.md` 파일을 열어 내용을 복사합니다. 챗GPT의 **프로젝트 지침**이나 **맞춤형 GPT 지침**에 붙여 넣으면 같은 방법으로 일합니다.

## 그림과 영상 스킬을 쓰려면: 힉스필드 연결

그림, 영상, 목소리 인공지능을 한곳에 모은 서비스(힉스필드)를 클로드에 꽂으면, 대화 안에서 바로 그림과 영상을 만듭니다.

1. [higgsfield.ai](https://higgsfield.ai) 에 가입합니다. **유료 구독과 크레딧이 듭니다.**
2. 클로드 **설정 → 커넥터 → 새 커넥터 추가**에서 주소 `https://mcp.higgsfield.ai/mcp` 를 넣고, 힉스필드로 로그인합니다.
3. 이제 «이 상품으로 대표 이미지 만들어 줘»처럼 말로 시킵니다.

다른 그림, 영상 도구를 써도 됩니다. 스킬은 지시문(무엇을 어떻게 그릴지)을 짜 주고, 결과를 판정하는 데까지 돕습니다.

## 돈에 대하여

- 스킬은 공짜입니다.
- 그림과 영상을 만드는 서비스는 각자의 요금제를 따릅니다.
- 이미지, 영상 스킬은 **만들기 전에 크레딧이 얼마 드는지 먼저 묻도록** 되어 있습니다. «좋다»고 할 때만 만듭니다.

## 꼭 지킬 것

- **효능을 단정하지 않습니다.** 없는 인증, 없는 수치, 의학적 효과를 쓰면 광고법에 걸립니다. 숫자와 사실은 내가 가진 자료에서만 씁니다.
- **남의 얼굴, 남의 영상, 남의 상표를 쓰지 않습니다.** 잘 된 영상은 짜임만 배우고, 내용은 새로 만듭니다.
- **인공지능으로 만든 것은 표시합니다.** 예: 네이버 쇼핑라이브의 «AI활용» 표시.
- **마지막 확인은 사장님이 합니다.** 인공지능은 자신 있게 틀릴 수 있습니다.
